## 小程序本地演示模式（DevTools 免后端看界面）

`backend/pages.ts` 的 `registerPage` 会在 `wx.__fixtureMode === true` 时退回「页面 index.ts 里的本地实现」，而每个页面的本地实现本来就是完整的（`MOCK_POSTS` + 本地 storage）。据此在 `app.ts` 加了开关：

- `app.ts`：模块顶层（早于任何页面模块求值）按平台判定，`devtools` 即 `wx.__fixtureMode = true`；`wx.getDeviceInfo` 与 `wx.getSystemInfoSync` 双通道探测。escapse hatch 为 `wx.setStorageSync('xinkelink.mode','live'|'local')`。
- `pages/beta-access/index.ts`：fixture 模式下 `onLoad` 直接 `reLaunch` 到 `/pages/forum/index`，绕过内测门禁。
- **不能改 `app.json` 的首页顺序**：`tests/beta-access.test.cjs` 断言 `pages[0] === 'pages/beta-access/index'`。
- 真机始终走真实后端 + 门禁，不受影响。

后端为什么起不来：`apps/server` 需要 MySQL **13306**、Redis **16379**、`XINKELINK_JWT_SECRET_BASE64`、以及真实微信 AppID/Secret；而 `beta/access` 的 `allowed()` 还要求 `authenticated && activated`。本机只有 3306 的 MySQL，`target/backend-dev/*.jar` 是 11-11 的旧产物。`config.ts` 指向 `127.0.0.1:18086`，README 里写的是 18081，`application.yml` 是 8080 —— 三者尚未统一，接后端前要先对齐。
