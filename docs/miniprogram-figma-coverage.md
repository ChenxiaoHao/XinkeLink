## M01 首页和 M86 登录弹层

### M01 论坛首页

现状中福袋和发帖覆盖帖子正文与图片。复用 `page-header`、分类横滚、`forum-post-card` 和 `custom-tab-bar` 中现有的两个图标按钮。保持顶部、分类、信息流、右下悬浮操作和五栏底部导航的现有位置关系。帖子卡仍用左侧头像列，作者、正文、媒体、评论至点赞的互动区从同一正文起点对齐。建议外边距 16px，头像 38px，头像与正文间距 8px，正文起点 x=62px。作者、时间和更多共用原首行，长昵称允许在更多按钮之前收缩。评论、转发、点赞及更多的可点区域维持独立，目标 44px，保留原图标尺寸和交互。

在五栏上方为原右下悬浮按钮留一段固定高度的空白区域，滚动内容的可见底边止于该区域上缘。这样滑动经过按钮时正文和媒体仍可读。按钮沿用同一垂直轴，发帖 48px，福袋 44px，中心距右边 40px，两按钮相隔 8px，发帖距底栏 10px，最上方按钮距信息流底边 8px。有福袋时预留 118px，无福袋时预留 66px。搜索 M12 和通知 M16 复用同一浮动按钮布局规则。原条件决定是否显示福袋。这个高度标注以现有底栏总高度 `54px + 底部安全区` 为基准。

| 标注示例 | 滚动内容底边 | 福袋触区 x / y | 发帖触区 x / y | 底栏起点 y |
| --- | ---: | --- | --- | ---: |
| 375 × 812，底部安全区 34px | 606px | 313–357 / 614–658 | 311–359 / 666–714 | 724px |
| 390 × 844，底部安全区 34px | 638px | 328–372 / 646–690 | 326–374 / 698–746 | 756px |

两宽都用长文、单图、四图和连续三条帖子测试。慢拖和快速滑动时，卡片正文、图集和末条互动可完整滚出按钮区域。检查下拉刷新、触底分页、分类切换、分享定位及从详情返回。正文点按进入对应帖子，头像、图集、更多和互动保持各自原有结果。关闭福袋或返回详情后，以同一帖子 ID 和相对视口位置核对回流。改变分类仍走现有回顶路径。 [M01 现状截图](../.local/ui-audit-20261120/mini/M01.png)

### M86 登录弹层及 M54 抽屉触发

现状中，独立页面内打开 `profile-auth-sheet` 时，福袋、发帖及五栏位于表单上面。`requestProfileConsent` 已设 `publishVisible: false`，当前自定义底栏的两个按钮模板仍以 `activeKey`、`drawerVisible` 和活动 ID 决定显示。核对时同时观察页面级弹层、抽屉内弹层和独立原生登录提示。M86 截图是开发者工具夹具隔离出的遮挡场景，真实入口由需要会话的现有动作触发，需真机复测。

复用 `profile-auth-sheet`、品牌标记、头像选择和微信昵称输入。保持底部面板和现有顺序「标题与关闭 → 说明 → 头像 → 昵称 → 现有错误 → 确认并登录 → 暂不登录」。水平留白 16px，标题右侧关闭触区 44 × 44px，头像和昵称各至少 52px，确认和取消各至少 44px。说明和错误允许换行，表单在可用高度内可滚动，键盘上方保留到确认、取消的滚动路径。键盘收起时面板保留底部安全区，键盘出现时以实际键盘顶边校验面板高度，避免叠加两个底部偏移。

| 现有状态或操作 | 375px 和 390px 的验收条件 |
| --- | --- |
| 页面动作打开登录 | 全屏遮罩拦截背景点按与滚动。底栏在遮罩下面，福袋和发帖仅在弹层期间隐藏。头像、昵称、确认和取消完整可达。 |
| 抽屉内通过微信授权登录打开 | 保留被遮罩的原抽屉上下文，关闭后回原抽屉及位置。页面级登录关闭后回页面而非打开抽屉。 |
| 选择头像、系统返回、昵称聚焦 | 真机检查 `chooseAvatar` 与 `type="nickname"`。系统选择取消保留当前弹层与已有输入。键盘升降时焦点、输入和操作可达，安全区无叠加留白。 |
| 暂不登录、右上关闭、点遮罩 | 非保存中三条现有取消路径返回原触点，保留当前页、选中分类或分栏及滚动位置。底栏和两个入口按打开前的条件恢复，取消不继续执行被拦截的动作。 |
| 保存中、保存失败及成功 | 保存中拦截重复提交和退出。失败时现有错误可见、输入可继续编辑。成功后按原入口回流或继续原操作，验证返回后的滚动与导航状态。 |

真机覆盖 iOS、Android、微信头像授权与昵称键盘。在首页下滚后以访客点赞，另从搜索、通知、私信、AI 的现有登录或受保护动作验证共享组件。 [M54 抽屉登录截图](../.local/ui-audit-20261120/mini/M54.png) · [M86 独立登录截图](../.local/ui-audit-20261120/mini/M86.png)
