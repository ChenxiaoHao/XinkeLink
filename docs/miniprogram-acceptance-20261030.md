# 微信小程序实际验收补充记录

日期：2026-10-30。范围：补齐上一轮的登录、点赞联动、搜索与手机尺寸验收；单线执行，没有子 agent。本轮未修改产品业务代码、未执行 Git commit/push/reset/clean、未接 OSS。

## 结论

本轮核心模拟器验收通过：19个注册页面分别在375×812和430×932完成实际加载及横向溢出检查，共38项。登录资料确认两次由用户本人操作；真实页面事件经本地正常后端和MySQL执行点赞、取消、查询及搜索，未拦截API或回退Mock。

这不等于真机或生产环境验收，也不表示所有页面都完成逐像素视觉审查。

## 1. 环境与验证方法

- 微信开发者工具 Stable v2.01.2510290，真实小程序AppID，正常本地后端 `http://127.0.0.1:18081`。
- 375×812：iPhone X；430×932：iPhone 15 Pro Max。通过工具真实机型菜单切换，并用`wx.getSystemInfoSync()`核对，未伪造屏幕尺寸。
- 页面检查用真实小程序运行时与`createSelectorQuery()`读取已渲染视口和控件边界。单页失败标记、资料弹层异常、横向滚动宽度均检查。
- 点赞、搜索等多数动作通过自动化调用真实页面事件方法，实际执行正常HTTP请求和服务端持久化；不是人在屏幕上逐个点击所有按钮。头像昵称确认由用户本人实际操作。
- 工具旧调用有超时：同步wx API不应通过等待success回调的异步桥调用。本轮改用同步读取；有返回Promise的页面动作通过发起后读取真实状态验证，不再等待失效的页面方法桥。
- 截图白屏通过重启开发工具并禁用GPU加速解决。临时定位截图已移除，只保留两张必要页面结果；没有更改产品UI以迁就截图。

## 2. 登录与会话

| 项目 | 实际证据 | 结果 |
| --- | --- | --- |
| 首次资料确认 | 用户本人选择头像、填写昵称并确认；随后运行时loggedIn=true、profileConfirmed=true，头像昵称存在、authVisible=false、loadFailed=false | 通过 |
| 重新加载恢复 | 多次真实机型切换触发重新编译/加载后保持同一账号，不再弹出资料确认 | 通过 |
| Token提前刷新 | 将本地刷新调度的expiresAt设为已到期，再重新加载；真实后端返回新Token、账号不变、到期时间更新、资料确认标记保留 | 通过 |
| 主动退出 | 真实设置页退出和确认；本地会话为空，旧Token访问/me返回401，匿名帖子浏览返回200 | 通过 |
| 退出后重新确认 | 再次点击登录确实弹出资料确认，用户第二次手动选择头像昵称并确认，运行时登录与资料标记正常 | 通过 |
| 验收后状态 | 已登录，停在“我的”页面，430×932，没有遗留登录弹层或错误状态 | 正常 |

Token测试主动触发的是客户端提前刷新，不冒充“等待服务端签名自然过期”的完整实测。原始`real-refresh.json`的综合passed字段为false，是因为该步骤的机型菜单最初选中了360×640；其中认证子项均成功，随后真实切换为430×932并完成整组检查。原始失败记录保留，没有篡改成通过。

没有代替用户点击头像昵称授权，没有打印Token、AppSecret或其他密钥。用户两次回复均确认昵称头像显示正常。

## 3. 点赞、搜索与错误反馈

- 商品2822从未点赞/0变为已点赞/1，进入“我的点赞”；商品详情返回同一状态和数量；详情取消后回到0并从点赞列表移除。
- 帖子5715的列表与详情联动检查后已恢复原始点赞状态（true/1）；第二组使用原本未点赞的4478验证加入、详情、取消、移除，最终恢复false/2。
- 实际视口滚动位置在点赞前后均为300px，页面reload调用次数为0；保留列表内容，不整页刷新。
- 输入“充电器”时不立即搜索；确认后真实帖子结果1条。搜索“键盘”得到真实商品1件。
- 不存在的关键词返回零结果；清空后返回未搜索状态。测试新增的本地搜索历史已还原。
- 查询不存在的商品时显示真实失败状态，随后正常页面仍可读取；没有用Mock填充或显示虚假成功。
- 本轮11项功能检查全部通过。没有实际制造点赞时的网络中断；该异常路径不在本轮真实故障注入验收范围。
- 旧收藏表保留，验收后数量1222；本轮没有调用收藏接口或执行收藏转点赞。新增测试点赞均已恢复，未删除业务数据。
