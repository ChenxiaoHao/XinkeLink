# 头像昵称确认与小规模学生预览（2026-10-26）

本轮沿用已通过真实微信联调的服务端认证，不更换微信身份、不构造测试登录成功。本次只调整前端资料确认流程，完善本地展示数据及修复商品封面比例。

## 登录与资料

- 游客点击「登录」或执行受保护操作，先在当前页面打开统一底部资料确认层。
- 头像使用原生 `button open-type="chooseAvatar"`，昵称使用 `input type="nickname"`。用户主动选择头像、快捷填写微信昵称后确认；不是仿造的微信统一授权窗口，也不声称能静默取得微信资料。
- 昵称以 `form bindsubmit` 的最终表单值为准；头像、昵称未填写不能确认。
- 确认后依次执行真实 `wx.login`、既有 `/auth/wechat`、头像上传（purpose=avatar）、读取资料版本、`PATCH /me`，随后更新共享会话资料和当前页面。已有刷新 Token 机制保持不变。
- 弹层取消不调用登录；保存失败保留错误信息、撤销这次不完整会话，不继续原来的点赞等操作。并发受保护操作等待同一确认流程；页面离开会取消等待，聊天原有清理逻辑保留。
- 没有恢复独立登录页导航。当前已登录账号可以退出后再次点击登录体验弹层，或在资料编辑中主动更新头像昵称。
- 官方组件依据：[微信小程序官方头像昵称组件](https://github.com/wechat-miniprogram/mp-user-avatar/blob/master/README.md)。真机的微信头像、昵称快捷选择仍需用户主动操作；自动化没有替用户选择资料或改写现有真实账号头像昵称。

## 商品图片

原适配器把 `170 / coverRatio` 当成 rpx 高度，实际卡片宽度接近335rpx，导致用户截图中的照片被压成窄条。改为按卡片自身宽度计算百分比留白，图片绝对定位占满该区域并使用 aspectFit；非法比例回退4:3。3件在售商品均有完整可访问图片，不再使用1×1验收图片。
