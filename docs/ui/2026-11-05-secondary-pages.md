## 实现与修正

- 复用现有 `page-polish.wxss`、`chat.wxss`、卡片和返回栏，不新增共享 WXSS 导入。
- 原生 picker 使用现有分类、成色枚举，当前值对应当前选中项；非法选择和忙碌状态不覆盖草稿。
- “我的帖子”接回已存在的编辑入口。发现真实编辑流程未向 WXML 暴露 `editId`，导致标题/按钮仍是发布态；已补齐显示状态。原 PATCH 请求、所有权检查和正文不变。
- 修正残留蓝色空态按钮、分类下划线、发布辅助文字、评论操作色；商品详情去掉重复面交信息，日期重复文字已修正。
- 学号仍仅在本机保存；专业、班级和入学年份标注“用户自填，未经平台核实”。
- 不添加没有真实能力的控件：聊天继续只发送文字，没有新增图片发送空按钮；联系未新增独立搜索。设置保留“我的”菜单入口。
