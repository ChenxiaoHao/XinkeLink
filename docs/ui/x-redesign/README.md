## 产品口径（第二轮已收窄）

四条硬约束，所有界面都按这个来，不再有例外：

1. **帖子只有三个动作**：评论 / 转发 / 点赞。没有书签、没有分享、没有复制链接。
2. **个人主页只有两个 tab**：帖子 / 喜欢。没有媒体、没有回复、没有关注体系。
3. **搜索页只有「热门」一个列表**：按当天点赞数排序，没有探索 / 趋势 / 帖子三 tab，没有用户搜索。
4. **AI 保留，但只做免费**：不做充值、不做额度、不做会员墙，界面上不出现任何价格 / 积分 / 升级入口。底栏第 3 格和抽屉里都有 Link AI 入口，都挂「免费」标。

## 逐屏要点

**① 首页**：顶栏「头像 32 + 品牌剪影 24 + 胶囊避让 32」。分段 tab 用真实维度：推荐 / 最新 / 校园 / 失物 / 学习 / 互助。34px 工具条保留筛选与公告。帖卡三态：文字+单图、纯文字匿名、文字+四宫格。**动作行三项，SPACE_BETWEEN 摊平**：评论（气泡+12）/ 转发（双向箭头+3）/ 点赞（心形+48）。

**② 个人主页**：封面 150（无封面上传 → 品牌蓝渐变默认态）、返回与更多圆形按钮 34 叠在封面上（右侧按钮按 `menuRightSpace` 让开微信胶囊）、头像 88 压边 36（白环 + 内头像双层，解决「头像被裁成半圆」）、昵称 20/800、专业·班级·年级行、统计行（动态数 / 获赞数）、两个白胶囊按钮（分享个人资料 / 编辑个人资料）、**两个文字 tab：帖子（蓝色 4px 下划线，宽 56 居中）/ 喜欢**。
> 与画稿的两处差异：① 画稿的 `@handle` 后端没有 handle 字段，换成真实的「专业 · 班级 · 年级」；② 画稿的「2026年6月 加入」需要 `xl_user.created_at` 暴露到 `/users/:id`，暂时不显示，不编造时间。

**③ 热门**：头像 + 搜索胶囊 + 齿轮；**没有 tab 条**，改为 48px 标题条：「热门」20/700 + 右侧「今日 · 按点赞排序」12 灰。列表 6 行 = 排名（17/700，前三名 `#0F1419`，四名后 `#536471`）+ 两行摘要（15/400 行高 21）+ 元信息（`作者 · N 万赞` 13 灰）。行间 1px 分割线，**没有条数、没有趋势概念**。

**④ 通知**：头像 + 居中「通知」+ 齿轮；tab 全部（带铃铛）/ 未读；行结构 = 类型图标 20（评论蓝 / 点赞粉 / 公告紫）+ 头像 34 + 三段式文案（昵称加粗 + 摘要 + 右侧时间）+ 缩略图 56，**行间不用分割线**。类型全部来自后端已有的 comment / reaction 两类通知 + 公告；「未读」是前端按 `unread` 过滤，不需要新接口。

**⑤ 私信**：头像 + 居中「聊天」；搜索框与「全部 ⌄」胶囊放在同一行（画稿把胶囊放右上角，会和微信胶囊重叠，必须让开）；空态气泡图标 56 + 「无私信」+ 说明；会话行头像 48、昵称 15/700、时间 13 灰、预览 15 灰 + 未读蓝点。

**⑥ 抽屉**：宽 84%（315），遮罩 50% 黑。头像 44 +「陈浩」17/700 + `@handle` + 统计行。菜单：个人资料 / 我的帖子 / 书签 / 草稿 ｜ 设置和隐私 / 帮助与反馈。X 专属的订阅、Money、社群、列表、空间、创作者工作室已删除。**抽屉里不放 AI 入口**——AI 的唯一入口是底栏第 3 格那颗星。

**⑦ 帖子详情**：顶栏「返回 24 + 帖子 17/700 + ⋯」。主帖：头像 40 + 昵称/`@handle` 双行 + 正文 15/20 + 配图 176（圆角 16）+ 时间行（`下午 2:31 · 2026年11月12日 · 236 次浏览` 13 灰）+ **44px 动作行（三项摊平，18px 图标，点赞计数取 `#F91880`）**。8px 灰带分隔 → 「回复」16/700 + 右侧「按热度」蓝色 → 一级评论（头像 32 + 昵称/时间 + 正文 14/19 + `5 赞 · 1 条回复`）→ **缩进 56px 的子回复（头像 24 + 13/18）**。底部固定回复栏 52 + 安全区：头像 28 + 圆角输入框「发布你的回复」。

**⑧ 发帖编辑器**：顶栏「取消 / 发布（蓝色胶囊 34）」。头像 40 + 正文 17/24 + 已附图 220（圆角 16，右上角 28px 半透明黑圆 + 白色 ×）+ 话题 chip（`#图书馆插座` 28 高胶囊，底 `#E7F5FE`、字 `#1D9BF0`）。底部工具条 52：图片 / 话题 / 表情（22px 蓝色描边）+ 右侧 `18/500` 计数。

**⑨ 设置**：返回 + 「设置」。账号组（头像 48 + 昵称 17/700 + 「查看个人主页」13 灰）→ 8px 灰带 → **通知设置（默认折叠，值「全部开启 / 部分开启 / 全部关闭」，点开就是那 4 个开关）** / 资料与隐私说明 / 意见反馈 / 关于信科 Link（值 V1.0.0）→ 8px 灰带 → **退出登录（`#F4212E` 居中）** → 页脚 13 灰。行高 56。
> 画稿的「黑名单」「隐私设置（回复默认公开）」后端没有对应能力，不做空开关。

**⑩ Link AI**：顶栏「Link AI 17/700 + 蓝色『免费』标 20 高 + 右侧 ＋ 新对话」。**底部保留主导航**（和首页 / 热门 / 通知 / 私信一致），第 3 格星标为实心 + 上方蓝点表示当前所在位置，其余四格全描边 —— AI 是第 5 个主 tab，不是一个二级页。输入栏压在底栏之上：`y 673 / 高 52`，对话区 `高 576`，不能让它压到底栏。

**AI 消息不用气泡**（X 的 Grok 就是这个做法）：紫色 `#7856FF` 圆 28 + `✦` + 全宽正文 15/21，视觉上比用户发言轻。用户发言是右对齐蓝气泡（宽 236、圆角 16、内边距 10/14、白字）。AI 回复底部跟两个描边小按钮「复制 / 直接发帖」，直接对接编辑器。空白处用弹性撑开把「试试这样问」+ 4 个建议 chip 推到输入框上方。

**免费怎么表达（重要）**：整条链路只有两处免费暗示，没有任何支付痕迹 —— ① 顶栏「免费」标 ② 开场白「免费使用，不限次数」。**没有**充值、积分余额、剩余次数、Pro 升级、试用倒计时。这是刻意留白的，别在落地时"顺手"加上额度提示。

AI 的三条实际职责（都贴着论坛场景，不是通用聊天）：写帖子草稿（产出可直接点「直接发帖」进编辑器）、把长讨论缩成三句、润色 / 起标题、判断该发哪个板块。**不做联网搜索、不做图片生成**——两项都要花钱，和「免费」冲突。

## 与 X 的必然差异（不是缺陷）

1. 状态栏与右侧微信胶囊由系统绘制，位置不可改；品牌 mark 无法绝对居中于屏幕
2. X 的滚动吸顶毛玻璃小程序不支持，改用 1px 分割线
3. X 用自有图标集，本稿按几何重绘为 SVG，允许 ≤1px 造型偏差
4. 无关注体系 → 「正在关注」tab 不出现，主页与抽屉用「动态数 / 获赞数」替代关注数字，不做推荐关注卡
5. 无认证体系 → 不打蓝标
6. 无用户搜索接口 → 热门榜只排帖子，不做用户 / 话题维度
7. 搜索页没有 tab 条（X 是 4 个 tab），因为需求只有一个「热门」

## 落地前必须补的后端能力

**转发**：现在库里只有 `like` / `comment` 两类互动，没有转发表。要么补 `post_repost(post_id, user_id, created_at)` + `POST/DELETE /posts/:id/repost`，要么这个按钮点下去没有反应。同一条帖子被同一人重复转发要算幂等。

**热门排序**：需要一个按「当日点赞数」聚合的查询（`like` 表按 `created_at::date = today` 分组 count 后 join `post`），冷启动时当日无赞要能回退到近 7 天。

**AI 免费怎么落地**：不要接按 token 计费的自建 API 再转嫁给用户。「免费」要成立只有两条路 —— ① 用平台侧免费额度（腾讯云/DeepSeek 等有免费档，走服务端代持 key，前端永不出现 key 与额度）② 限频不限量（如每人每分钟 3 次），限频提示也不能写成"额度用尽"。**数据库里不要建 `ai_quota` / `ai_credit` 这类表**，一建就会长出付费墙。
