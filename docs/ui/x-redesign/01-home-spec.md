## 6. 本稿的四个决策（已定稿）

1. **分段 Tab 用真实维度**。不做关注体系 → 「正在关注」不成立。改为 6 个真 tab：推荐/最新（排序）+ 校园/失物/学习/互助（后端已有 category）。X 本身也是「算法+关系+主题」混排，语义成立。
2. **动作行只有三项：评论 / 转发 / 点赞**（第二轮按「不用太复杂」收窄）。原来的「复制链接 / 书签 / 分享到微信」三位已删除。**转发需要补后端接口，见 README「落地前必须补的后端能力」。**
3. **头部无「认证」蓝标**。项目口径是「用户自填，未经平台核实」，不做假认证。
4. **底部导航五格：首页 / 搜索 / Link AI / 通知 / 私信**，每格 75，图标框 32.5 居中（x=24.5）。Link AI 图标按 Grok 几何重绘为「四角星 + 小星」，抽屉里同步保留入口并挂「免费」标 —— **AI 是免费功能，不做任何付费入口**。

## 7. 与 X 的已知差异（不可消除，非缺陷）

- 顶部状态栏与右侧微信胶囊由系统绘制，位置固定，品牌 mark 无法绝对居中于屏幕
- X 的滚动吸顶毛玻璃效果在小程序不支持，此处用 1px 分割线替代
- X 图标为自有图标集，本稿按几何重绘为 SVG，允许 ≤1px 造型偏差
