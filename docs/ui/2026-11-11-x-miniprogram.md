# 信科 Link：X 手机端首轮改造记录

日期：2026-11-11。用户已确认按首页／搜索／Link AI／通知／私信五入口方案实现。保持原生 TypeScript、WXML、WXSS 与既有真实 API。

## 已实现

- 五个原生 tab 与自定义图标底栏；首页、搜索上的独立悬浮发布按钮；通知与私信分离未读徽标。保留动态和闲置两种发布流程。
- 首页改为白底贴边信息流、推荐／关注双标签、蓝色指示条、横向滑动切换；分类和公告保留紧凑入口。
- 共享帖子组件改为头像左列、作者时间同排、正文及媒体右列、回复／转发引用入口／喜欢／书签／分享五操作。原图片预览、图片续期、匿名保护、举报、原地互动更新保留。
- 头像打开个人侧栏，含主页、校园交易、书签、草稿、我的帖子／闲置、设置／反馈；支持遮罩关闭和向左滑动关闭。打开时设置底栏隐藏状态以避免控制互相遮挡。
- 搜索成为主入口，保留历史、动态与商品结果和分页；交易搜索通过本机短期入口状态传递商品分类，适配 switchTab 不支持查询参数。
- 新增独立书签页，使用既有 `/me/favorites` 与帖子 favorite 接口，和“我的点赞”区分；补充选中帖子分享路径。
- 新增本机文字草稿保存、列表与继续编辑；临时图片不作为可持久草稿保存。闲置草稿沿用原实现。
- 新增 Link AI 输入与建议问题界面，显示服务接入状态。
- 交易和个人页移出 tab 后增加返回按钮；同步替换原 switchTab 路由、调整登录后与返回失败时的跳转。
- 统一核心色值、共享返回栏和个人主页／公开主页视觉。新增 `scripts/generate-x-icons.cjs`，从已有 Lucide 依赖生成所需 PNG。

## 未完成的目标与边界

- 当前真实后端没有启动，本轮未执行真实登录写入、收藏写入、实时消息或微信分享送达联调。
- 关注关系和关注信息流、站内转发／引用发布没有对应服务；界面明确显示接入中，不用最新动态代替关注，不伪造转发成功或计数。
- AI 后端未接入；没有生成伪造回答。
- 个人侧栏没有编造关注／粉丝数量；列表入口也未伪造列表系统。
- 发布入口已统一，两类内容仍使用各自已有编辑器，尚未合并成一个支持切换类型的编辑器。
- 本轮为首轮界面与信息架构改造，尚未达到用户要求的全部页面、全部交互逐像素一致。需要继续补齐上述服务、统一发布器并做真实设备视觉与交互验收。
