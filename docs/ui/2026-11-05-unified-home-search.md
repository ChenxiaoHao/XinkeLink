# 首页搜索入口统一

按用户第三张截图，论坛和交易均取消品牌头部的独立搜索图标，改用同一组 `home-search-*` 样式：白色圆角底托、浅灰搜索栏、右侧白色圆形筛选按钮。

- 论坛提示为搜索动态，进入原有帖子搜索；右侧用原生菜单选择现有六个分类，仍委托原来的分类处理，不增加业务筛选条件。
- 交易提示、商品搜索类型及原来的排序/筛选动作不变。
- 公告、Logo、卡片、底栏样式与位置保持；底栏文件与本轮备份一致。
- 修改：论坛 WXML/TS、交易 WXML、共享 `page-polish.wxss`；新增 `home-search.test.cjs`。

验证：类型检查、241 项测试、工程检查通过；28 WXML、32 WXSS 官方编译通过。新增测试覆盖分类委托、无效选项和取消菜单时保持原状态。

真实模拟器已确认论坛头部搜索关闭、新搜索栏可见（宽 398px、高 50px），点击后进入帖子搜索。[论坛截图](../../.local/unified-home-search-20261105/forum.png)。工具型号仍为 iPhone 15 Pro Max。
