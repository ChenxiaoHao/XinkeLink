- 原图片比例、展示模式、标题行数和数据字段没有改变。
- 两个首页的 TypeScript 页面文件、客户端 API 层、五栏导航、Logo、app.json 与本轮开始前逐字节相同。
- Java 后端与 PC 管理后台没有改动，没有 Git commit、push、reset、clean。
- 样式通过首页皮肤和组件 `home` / `polished` 开关限定范围。
