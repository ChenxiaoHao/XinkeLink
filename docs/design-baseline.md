# 设计依据与公共变量

## 已有材料

- stitch-overview-01.png：交易首页、发布选择弹层、联系首页、论坛首页。
- stitch-overview-02.png：我的、帖子详情、商品详情、商品关联聊天。
- 来源：用户 2026-10-22 提供的两张拼图，实现前已打开检查。

本阶段只实现公共结构和四个页面容器，不填充模拟学生、商品、消息、认证或统计。缩小拼图不作为精确标注稿。

## 直接依据

- 用户指定主题色 #6489B8；浅色背景、白色圆角卡片和轻阴影。
- 五个视觉位置依次为论坛、交易、圆形加号、联系、我的；中央按钮打开选择面板。
- 面板从底部出现，含提示线、标题、副标题、关闭按钮、帖子与闲置两张卡片、底部提示。
- 详情和聊天使用各自底部操作区，本阶段不实现这些页面。

## 暂定变量

除主题色外，以下数值从拼图估算，收到高清稿或标注后集中调整。

| 语义 | 值 |
| --- | --- |
| primary | #6489B8 |
| primary-strong | #3D638E |
| primary-soft | #EEF3FD |
| background / surface | #F7F8FD / #FFFFFF |
| text / muted / border | #202C3E / #8A93A3 / #E8ECF4 |
| spacing | 4 / 8 / 12 / 16 / 24 / 32 px |
| radius | 8 / 12 / 16 / 24 px |
| shadow | 0 2px 10px rgba(42,64,97,.06) |

小程序尺寸按 375px 视口转换成双倍 rpx；后台使用 px。两端独立维护同名变量，不引入共享构建。

UI 图标采用 Lucide 开源线性图标，生成本地 PNG，作为匹配截图的暂定资源；不将其当作未提供的正式 Logo。

## 交互范围

- 四个 tab 可切换，当前页同步选中态，跳转失败保留原选中。
- 中央按钮打开面板；遮罩和关闭按钮关闭；卡片发出 post / product 选择事件。
- 选择后显示“已选择发布帖子/闲置”，不假装发布成功，不创建未提供的编辑器。
- 面板阻止背景滚动并保留底部安全区；原生渲染和手势仍须微信工具及真机检查。
- “已认证学生”“关注”等入口等待身份文案与功能范围确认。
