# 论坛核心前端续建

依据本轮用户要求自主连续执行，不等待逐步确认、不提交、不切换或清理工作区。开始快照 .local/forum-core/baseline.json，原有 70 项小程序测试通过。

设计：详情依据 docs/references/stitch-overview-02.png 第二张画板 x362 y63、236×575；发布依据 market-publish-overview.png 第三张画板顶部 x844 y101、334×94。发布正文细节未给出完整画板，按本轮授权沿用既有表单、变量和图片选择规范，不重新设计品牌或五栏导航。复用头像、帖子图片、back-header、现有图标体系，不生成新素材。

数据：维持现有帖子、交互 storage key；新增本地帖子和评论状态。所有修改在读取校验成功后单次写入，失败不覆盖旧数据。详情和首页都从相同仓库读取；匿名作者仅在内部存储保留身份，传入页面和分享的数据采用公开投影。评论二级封顶，回复指向一级父评论，删除自己的一级评论连带其回复并先确认；不能删他人评论。评论基数与完整模拟评论记录一致。编辑正文上限 2000 字、1–9 张可选图片、四个业务分类，正文非空。文件持久化与失败回滚使用论坛独立目录，不改交易模块。

接口预检：详情、评论、发布与首页均依赖仓库 readForum/readPosts/getPostView；交互沿用 version1；local-post ID 需纳入归一化。先定义这些接口，再逐步接入页面。用户本轮要求优先于技能中的逐步确认、提交和分支收尾建议；全程保留现有 checkout。
