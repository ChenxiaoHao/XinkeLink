# 校园二手前端实现计划

> **For agentic workers:** Use executing-plans to implement the tasks in order. 本轮由主代理在当前工作区实现，图片资源独立生成。

**Goal:** 按用户补充的 Stitch 图实现交易首页、商品详情、发布闲置，并串联商品关联的本地模拟聊天。

**Architecture:** 原生小程序；交易类型、查询和本地仓库置于 features/market。新增商品卡片与返回头部，不修改论坛、Logo、五栏导航和原发布选择组件。详情与编辑页各自保留底部安全区。

**Tech Stack:** TypeScript / WXML / WXSS，现有 Node 测试，无新增运行依赖。

**Spec:** 用户本轮交易模块要求；2026-10-22 221703、221713 两张总览和补充图片左侧「发布闲置」表单。截图是视觉依据，截图内的其他业务不在本轮实现。

## 约束与裁定

- 主题 #6489B8，沿用现有变量、公共头部、字体、圆角和原生图标资源。
- 综合、最新、价格和筛选使用现有版式；搜索和筛选选择使用微信原生弹窗，不设计未经提供的新页面。
- 详情「查看主页」展示卖家资料原生弹窗；「我想要」进入该商品的模拟会话，仅含关联卡片、已有消息和本地发送。
- 发布标题在描述卡片内使用独立输入行；分类沿用首页六类，成色采用表单图的全新/99/95/9成新/8成及以下。截图中的话题 chips 不引入话题功能。
- 本轮不新增视频能力；表单图片区域保留主图、添加图片和预览。底部存草稿按截图保存至本地。
- 用户已明确允许仅接通现有中央发布闲置的跳转：只改 custom-tab-bar/index.ts 的 product 分支，WXML/WXSS 与五栏布局不变；不另加发布入口。
- 不提交本轮代码，保留供用户验收；不改 PC、Java 或后端连接。

## Review Focus

- 搜索/筛选后分页不重复；价格用分存储，排序按数值。
- 已售商品可看详情但不能发起新咨询；无效 ID 提示返回。
- 本地存储损坏或写满有反馈，收藏不假成功。
- 图片选择取消、超过9张、预览失败、移除主图和恢复草稿。
- 发布中防止重复提交，发布成功可在交易首页及详情找到，重进仍保留图片。
