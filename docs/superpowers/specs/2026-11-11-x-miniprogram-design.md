# 信科 Link：X 手机端界面改造

用户于 2026-11-11 确认“按此方案实现”。目标：保留信科 Link 品牌与校园业务，全面对齐 X 手机端的信息架构、视觉、组件和交互。

- 五个主导航：首页、搜索、Link AI、通知、私信。交易与我的改为普通页面，经搜索、头像侧栏进入。普通页面不得再使用 switchTab 跳转。
- 首页：头像与品牌顶部、为你推荐／正在关注双时间线、白底贴边帖子、灰色分割线、蓝色活动标识、右下角发布按钮。点击与水平滑动切换时间线，保持滚动分页与原地互动更新。
- 侧栏：头像、昵称、简介、个人主页、交易、书签、草稿、设置入口；遮罩、关闭、滑动关闭、安全区域适配。
- 帖子：头像左列，作者与时间同排，正文与媒体右列；回复、转发/引用、点赞、书签、分享。图片预览、匿名隐藏、举报与鉴权继续保留。
- 搜索：搜索栏、动态／闲置结果与历史。通知和私信独立页面，复用真实消息与通知接口。
- Link AI：独立页面；当前没有 AI 服务，显示接入状态，不伪造回答。未具备关注／转发服务时明确提示，不将最新时间线冒充关注流，不伪造计数。
- 发布：同一个入口选择动态或闲置；保留既有发布接口，统一编辑器的顶部操作、正文、图片和底部工具。
- 视觉基准：白色 #fff、文字 #0f1419、次要文字 #536471、边框 #eff3f4、蓝色 #1d9bf0、喜欢 #f91880。手机正文 15px、头像40px、横向边距16px，导航图标约26px。
- 不更换技术栈，不清理已有工作，不提交、推送或部署。微信系统区域保留原生行为。

参考：X 官方 https://help.x.com/en/using-x/x-timeline 、https://help.x.com/en/using-x/about-grok 、App Store https://apps.apple.com/us/app/x/id333903271 。公开截图因版本存在差异，以用户指定的五入口为固定基准。
